# Silent Guardian AI 🛡️

A real-time AI-powered safety companion application.

## Prerequisites

- [Python 3.8+](https://www.python.org/downloads/)
- [VS Code](https://code.visualstudio.com/)

## Installation

1.  Open the project folder in VS Code.
2.  Open a new terminal (Ctrl+` or Terminal > New Terminal).
3.  Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

To start the application, run the following command in the terminal:

```bash
streamlit run app.py
```

The application will launch in your default web browser at `http://localhost:8501`.

## Features

- **Live Safety Map**: Real-time visualization of safe and risky zones.
- **Guardian AI Chat**: Conversational safety assistant.
- **Sentinel Analytics**: Monitoring of biometric and environmental data (simulated).
- **Emergency SOS**: Quick trigger for emergency alerts.
